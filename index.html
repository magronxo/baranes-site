BARANES

Governed infrastructure for AI agents that act on real systems.

AI agents can plan, call tools and produce candidate changes. Baranes is designed to keep the path from intent to accepted effect bounded, traceable and reviewable.

RepoOps is the first concrete Baranes domain used to explain the model: repository work moves from bounded candidate execution to controlled canonical adoption.

The problem

Autonomy is easy to demonstrate. Controlled effects are harder.

AI agents can reason, call tools and modify code. The difficult boundary begins when an action must be attributable, bounded, reviewable and controlled before it becomes a real system effect.

“The agent produced a result” is not the same as “the system may accept the effect.”

Baranes is organized around that separation: intent, policy, execution capability, candidate state, evidence and canonical adoption remain distinct.

Bounded executionScope, paths, capabilities and stop conditions are explicit.
Effect governanceCandidate work is separated from canonical system effects.
Evidence firstExecution results, verification and provenance remain traceable.
