SDD Framework

Agent-first Spec-Driven Development with explicit, machine-readable contracts for repositories where humans and AI agents collaborate on software changes.

Apache-2.0Public repository
View repository ↗
What it provides

Lifecycle state that agents can read and tools can validate.

The framework installs into an existing product repository under docs/sdd/. Product source remains outside the framework tree.

01

Feature-record schema

Fields, types, enums, paths, aliases and record invariants for persistent feature state.

02

SDD protocol

Lifecycle transitions, gates, blockers, regressions and conditional checkpoints.

03

Validator + installer

Canonical contract validation plus deterministic installation into an existing repository.

Persistent lifecycle

From design to archive.

DESIGN → SPEC → VALIDATION → TASKS → IMPLEMENT → VERIFY → AUDIT → ARCHIVE
Machine-readable authoritiesThe feature-record schema governs record shape and invariants; the SDD protocol governs workflow behaviour and gates.
Current scopeFresh installation into an existing repository. The framework does not grant authority over external systems or replace external execution governance.
